# Changelog

## [1.0.0] - 2026-07-25
### Added
- Initial release of the `tree_memory_predictor` package.
- Restructured repository layout into a standard, distributable Python package format.
- Added comprehensive unit tests in the `tests/` directory covering core mechanics, predictive capabilities, federated learning, and serialization.
- Added GitHub Actions workflow `.github/workflows/tests.yml` for automated testing.
- Created standard `setup.py` for local installation and PyPI deployment.
